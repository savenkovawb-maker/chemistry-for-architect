# Химия для будущего архитектора

Интерактивный статический курс: 12 недель, 48 занятий.

## Что работает без сервера
- прогресс по занятиям;
- заметки;
- цифровой архитектурный планшет;
- интерактивная мини-таблица элементов;
- рисовалка;
- автопроверка ключевых вопросов.

Данные ученицы сохраняются локально в браузере через `localStorage`.

## GitHub Pages
Сайт не требует сборки. Публиковать `index.html` из корня ветки `main`.
